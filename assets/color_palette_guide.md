# AIS Water Bottle - Color Palette Guide

This guide lists all the available liquid colors you can use when designing levels in the JSON files.

**Total Available Colors: 16**
*(If you use an ID greater than 16 or less than 1, it will default to ID 1: Ocean Blue)*

| ID Number (Use in JSON) | Color Name | Description/Tone |
| :---: | :--- | :--- |
| **1** | Ocean Blue | Standard bright blue |
| **2** | Vibrant Orange | Solid orange |
| **3** | Ruby Red | Bright red |
| **4** | Emerald Green | Bright green |
| **5** | Royal Purple | Standard purple |
| **6** | Sunshine Yellow | Bright yellow |
| **7** | Electric Pink | Bright pink |
| **8** | Aqua Teal | Light sea green / Teal |
| **9** | Deep Navy | Darker blue |
| **10** | Lime Spark | Lime / Yellow-green |
| **11** | Amber Gold | Golden orange / Amber |
| **12** | Violet Dream | Violet / Magenta-purple |
| **13** | Cyan Frost | Ice blue / Cyan |
| **14** | Coral Glow | Red-orange / Coral |
| **15** | Mint Breeze | Dark mint green / Teal |
| **16** | Hot Magenta | Dark magenta / Deep pink |
